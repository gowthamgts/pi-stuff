# pi-silicon-valley

A [pi](https://pi.dev) package that displays a random quote from *Silicon Valley* whenever a session starts.

## Install

Install from npm:

```sh
pi install npm:pi-silicon-valley
```

Install from this checkout:

```sh
pi install ./extensions/silicon-valley
```

Restart pi (or run `/reload`) to load it.

## Notes

This is an unofficial fan package and is not affiliated with HBO or the creators of *Silicon Valley*. Quotes are attributed to their characters.
